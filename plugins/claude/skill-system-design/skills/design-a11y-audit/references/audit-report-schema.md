# Accessibility Audit Report Schema

Use this shape only for an audit artifact or several tracked conditions, and omit empty fields.

```yaml
target:
keyboard_result:
focus_result:
semantics_result:
contrast_result:
target_size_result:
responsive_readability_result:
manual_checks_needed: []
static_scan_hints: []
unresolved_gaps: []
unverified: []
```
