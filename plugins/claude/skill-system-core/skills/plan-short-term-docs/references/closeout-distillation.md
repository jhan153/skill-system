# Closeout Distillation

Use for completed, abandoned, superseded, or archived plans.

Record plan ID/final state, outcome, durable decision/lesson/failure-pattern candidates, artifact pointers, follow-ups with owner/trigger, archive target, future load policy, and verification status.

- Preserve pointers and short reusable decisions, not raw plan text.
- Keep uncertain lessons `unverified`.
- Keep proposals separate from actual Memory/Knowledge mutation.
- Put follow-ups in a backlog or next active plan, never default context.
- Accept `completed -> closed_out` or `closed_out -> archived` only when the required fields are present.
