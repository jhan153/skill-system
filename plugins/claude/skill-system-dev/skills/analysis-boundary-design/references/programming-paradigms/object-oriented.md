# Object-Oriented Selection Profile

- **Trigger:** identity, protected invariant, lifecycle, resource ownership, event addressability,
  a stable owner around volatile external representation, or current real runtime substitution is
  the governing property.
- **Non-trigger:** noun-shaped data, temporary state, testing convenience, or hypothetical future
  implementations alone.
- **Minimum closure:** one concrete owner, immediately valid final construction, explicit legal
  transitions/lifetime/failure, and a full behavioral contract for any genuine substitution.
- **Maximum scope:** the identity/invariant/lifecycle boundary; bulk values and deterministic
  kernels remain values/functions unless they have independent identity.
- **Interactions:** object/session shells may own procedural/functional kernels, data-oriented
  snapshots, Job scopes, or bounded static specializations.
- **Proof ceiling:** class/interface shape proves neither invariant enforcement nor substitutability;
  the implementation and representative lifecycle path must show them.

Implementation details and actual-path verification remain with the matching
`workflow-implementation` method profile.
