# Lifecycle Artifact Tiering

Use the smallest tier that satisfies the user's explicit artifact request.

| Tier | Use When | Typical Outputs |
| --- | --- | --- |
| 0 | Small fixes or one-shot tasks | No lifecycle package; use ordinary final reporting. |
| 1 | One selected delivery slice | Markdown index over the named existing sources and their evidence/status. |
| 2 | Several related lifecycle stages | Selected package plus only the relations needed between its existing artifacts. |
| 3 | Explicit whole-lifecycle traceability request | Full index over every supplied or authoritative source; missing stages remain gaps. |

Tier changes package breadth, not artifact authority. Never create a missing source merely to fill a
tier. Full lifecycle packages require explicit scope and identified source artifacts.
